# Diabetes Research

An explainable machine-learning study for early diabetes-risk prediction using
the Pima Indians Diabetes dataset.

## Setup

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run

```powershell
py -3 src\main.py
```

## Project layout

- `data/raw`: original datasets
- `data/processed`: transformed datasets generated by the pipeline
- `data/external`: optional external datasets
- `src`: source code
- `results`: figures, metrics, saved models, and reports
- `paper`, `references`, `presentation`: research deliverables
